# 개발일지 — 부품 사진 파일명 자동화 (hd-project10)

- 프로젝트: 부품 사진 품번·브랜드 AI 판독 → 파일명 일괄 변경
- 기획: 홍재영 (HD건설기계 AMPS기획팀)
- 개발: 2026-08-21 (hd-project08에서 1차 개발) → 2026-08-22 (요청 단위별 저장소 분리로 hd-project10으로 이관)
- 저장소: https://github.com/aebonlee/hd-project10

---

## 1. 요구사항 분석

- 실제 파일명 예시 스크린샷으로 규칙 확정: `연번3자리_품번_(브랜드).JPG`, 연번은 전역 증가, 새 부품 전까지 품번·브랜드 이어받기
- 기존 자동화 시도의 3대 오류(텍스트/숫자 오독, 브랜드 오독, 품번 이어받기 실패)를 해결하는 것이 핵심
- API 키는 Claude·ChatGPT·Solar 선택 사용 (기획자 확인 사항)

## 2. 설계 결정

| 결정 | 이유 |
|---|---|
| **검수(Human-in-the-loop)를 필수 단계로 설계** | AI 오인식을 전제로 함 — 그룹 분리/합치기, 품번·브랜드 수정이 그룹 전체 반영, 저신뢰 하이라이트 |
| OCR 혼동 문자 정규화(O↔0, I↔1, S↔5, B↔8, G↔6 등) 후 **완전 일치**로 같은 부품 판정 | `72O40`을 `72040`과 같게 보되, `72040`≠`71040`처럼 실제 다른 숫자는 구분 (테스트로 고정) |
| 품번 패턴 점수화(`15KA-72040` 형 구조 가중) + 전화/날짜 형태 배제 | 오독된 잡음 문자열이 품번으로 선택되는 것 방지 |
| 브랜드 사전(화면에서 편집 가능) + 복합어 우선 + 전 단어 퍼지(편집거리 1) 매칭 | HYUNDAI vs HYUNDAI CONSTRUCTION EQUIPMENT 구분, `HYUNDAl` 같은 오독 흡수 |
| 인식 엔진 어댑터 4종: Tesseract(무료·로컬) / Claude / OpenAI / Upstage | 기본은 사진이 외부로 전송되지 않는 로컬 OCR(라이브러리·언어데이터 동봉 — 오프라인 동작), 정밀 모드는 API 키 선택. 키는 브라우저 localStorage에만 저장 |
| 적용 방식 3종: 폴더 실제 변경(크롬/엣지 File System Access) / ZIP 사본 / Windows .bat + 매핑 CSV | 브라우저·보안 환경 차이와 무관하게 실무 적용 가능 |

## 3. 구현 내역

- `photo_renamer/js/logic.js` — 품번 추출·혼동 보정·같은 부품 판정·그룹핑·분리/병합·파일명 생성·자연 정렬·CSV/.bat 생성 (순수 로직, Node 테스트 가능)
- `photo_renamer/js/ocr.js` — 인식 엔진 어댑터 4종 (이미지 축소 전송 포함)
- `photo_renamer/js/app.js` — 폴더/파일 불러오기 → 인식(진행률) → 검수 화면 → 적용/내보내기
- 시작 연번 조정(기존 파일에 이어붙이기), 브랜드 사전 편집, 연습용 샘플 사진 7장(`make_samples.py`)

## 4. 테스트 및 검증

- `node photo_renamer/test/logic.test.js` — 품번 추출(전화/날짜 배제), 혼동 보정 동일 판정(`72O40`=`72040`, `72040`≠`71040`), 브랜드 정확/퍼지/복합어, 그룹핑·이어받기, 파일명(001~ 형식·시작 연번), 분리/병합, CSV/.bat — **전체 통과**
- **실사진 OCR E2E**(headless Chromium + 동봉 Tesseract): 샘플 7장 → 부품 3그룹 정확 판독, 라벨 없는 측면 사진의 품번 이어받기, `001_15KA-72040_(HYUNDAI).jpg` 형식 생성 — 콘솔 에러 0

## 5. 트러블슈팅

| 이슈 | 해결 |
|---|---|
| 같은 부품 판정이 과도해 실제 다른 품번(72040/71040)까지 동일 처리 | 혼동 문자 정규화 후 완전 일치로 엄격화 |
| 브랜드 퍼지 매칭이 복합어의 첫 단어만으로 오매칭 | 브랜드의 모든 단어가 발견될 때만 퍼지 허용 |
| 기본 OCR이 `file://`에서 동작 안 함(웹워커 제한) | 배포 페이지(http) 사용 안내, README 명시 |
