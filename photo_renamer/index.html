부품 사진 파일명 자동화

사진 속 품번·브랜드를 AI가 판독해 연번_품번_(브랜드) 형식으로 일괄 변경 — 검수 후 적용 ← 도구 목록

1. 인식 엔진 설정

⚠ 키는 브라우저에 평문 저장되며 사진과 함께 외부 API로 직접 전송됩니다 — 개인 발급 키만, 신뢰된 PC에서만 사용하세요. 기본은 세션 저장(브라우저 종료 시 삭제)이며, 팀/실서비스 배포 시에는 서버측 프록시로 키를 옮겨야 합니다(README 참고).

기존 파일에 이어서 번호를 매길 때 조정 (예: 12 → 012부터)

브랜드 사전 편집 (한 줄에 하나)

OCR 텍스트에서 이 목록과 대조해 브랜드를 찾습니다. 자주 쓰는 브랜드를 추가해 두면 인식률이 올라갑니다.

2. 사진 불러오기 촬영 순서 = 파일명 순서(자연 정렬)

아직 불러온 사진이 없습니다.

3. 검수 AI 인식 결과를 확인·수정하세요. 품번/브랜드를 고치면 그룹 전체에 반영됩니다.

4. 적용

폴더 모드: 선택한 폴더의 실제 파일명이 변경됩니다. 파일 모드: 새 이름의 사본을 ZIP으로 내려받습니다. .bat 스크립트는 사진 폴더에 넣고 실행하면 원본 PC에서 일괄 변경됩니다.
